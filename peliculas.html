🔑 Tu llave de TMDB

Es gratis y sirve para traer pósters, datos y tráileres reales.

  1. Creá una cuenta en themoviedb.org.
  2. Entrá a tu perfil → Ajustes → API y pedí una llave (uso personal).
  3. Copiá la Clave de la API o el Token de lectura y pegala acá.
La llave queda guardada solo en este navegador.
🎬 Acá ves tráileres oficiales. Para ver películas o series enteras gratis, tocá 🆓 Completas gratis: elegís una y abajo del tráiler te aparece la plataforma gratis donde se ve completa.
